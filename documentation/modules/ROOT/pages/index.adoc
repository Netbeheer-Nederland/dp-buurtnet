= Buurtnet

The Buurtnet data product supports the following use cases by providing all
required information:

* Activate residents to balance their energy consumption and generation based
on available data. By promoting self-organization and behavior change, we aim
to reduce peak load and decrease voltage issues, thereby bridging the waiting
time for neighbourhood-specific grid reinforcement.
* Provide customers in critical neighborhoods with insight and actionable
perspectives.
